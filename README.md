# PictureGift

Надлегкий портативний переглядач зображень і відео для Windows 11.
Один файл `PictureGift.exe` (~530 КБ), без інсталяції, без .NET, без жодних DLL.

Ідея — те, чим колись була Picasa: миттєве відкриття, зручне гортання папки,
сітка мініатюр — але на сучасному стеку й у дизайні Windows 11 (Mica, заокруглені
кути, акцентний колір системи, темна/світла тема, Segoe Fluent Icons).

---

## Швидкість

Заміряно на тестовій машині (24-мегапіксельний JPEG 6000×4000):

| Етап | Час |
|---|---|
| Декодування картинки | **25 мс** |
| Холодний старт (перший запуск) | ~300 мс |
| Відкриття у вже запущеній програмі | **9–10 мс** |
| Перехід на наступне фото в папці | миттєво (передзавантажене) |

Із ~300 мс холодного старту приблизно 270 мс — це `D3D11CreateDevice`, тобто
завантаження драйвера відеокарти. Саме тому програма за замовчуванням працює
в режимі **одного екземпляра**: друге відкриття картинки не створює новий
процес, а передає шлях уже запущеному вікну — і зображення з'являється за
десяток мілісекунд.

Як цього досягнуто:

* **Масштабування під час декодування.** Якщо фото більше за вікно, воно
  ніколи не декодується повністю. Для JPEG це вмикає DCT-масштабування
  (1/2, 1/4, 1/8) — у рази швидше, ніж декодувати все й потім зменшувати.
* **Миттєвий прев'ю-кадр.** Спершу береться вбудована EXIF-мініатюра або
  запис із кешу мініатюр Провідника — це одиниці мілісекунд. Повне
  декодування доганяє за мить і замінює картинку.
* **Передзавантаження сусідів.** Поки ви дивитесь фото, у фоні вже
  готуються ±2 наступні й попередні.
* **Пул потоків із пріоритетами й скасуванням.** Якщо швидко гортати
  папку, застарілі завдання відкидаються, а не стоять у черзі.
* **Декодування вищої роздільності на вимогу.** Коли ви наближаєте більше,
  ніж дозволяє поточний буфер, у фоні запитується повний розмір.
* **Direct2D + DirectComposition.** Масштабування й малювання — на GPU.

## Формати

Підтримується все, для чого в системі є кодек WIC, плюс власні запасні
декодери. На типовій Windows 11 це **76 розширень**, серед них:

`jpg` `jpeg` `jfif` `png` `gif` `bmp` `tif` `tiff` `ico` `dds` `webp`
`heic` `heif` `avif` `jxr` `wdp` `tga` `psd` `hdr` `pnm` `ppm` `pgm` `pbm`
`qoi` `cur` — а також формати RAW із камер, якщо встановлено відповідний
пакет кодеків (`cr2`, `nef`, `arw`, `dng`, …).

Список розширень будується **динамічно** при старті: програма опитує всі
встановлені кодеки WIC, тож щойно ви поставите з Microsoft Store, скажімо,
розширення для AVIF — воно запрацює без оновлення PictureGift.

Якщо WIC не впорався, у справу йдуть вбудовані декодери (stb_image: JPEG,
PNG, BMP, PSD, TGA, GIF, HDR, PIC, PNM; плюс власний декодер QOI).

### Відео

`mp4` `m4v` `mov` `mkv` `avi` `wmv` `webm` `mpg` `mpeg` `m2ts` `mts` `ts`
`3gp` `3g2` `asf` `ogv` `vob` `divx` `f4v` `m2v`

Відтворення — через Media Foundation Media Engine: декодування апаратне, звук
і синхронізація системні, кадри потрапляють одразу в текстуру D3D11, яку малює
той самий Direct2D, що й фотографії. Тому жодних додаткових бібліотек чи
кодек-паків не потрібно — працює все, що вміє сама Windows (H.264 завжди;
HEVC, AV1 і VP9 — якщо встановлено відповідні розширення з Microsoft Store).

Відео й фото живуть в одній папці й гортаються тими самими клавішами; коли
відкрито відео, панель інструментів автоматично стає панеллю плеєра
(таймлайн, пауза, перемотка, гучність, швидкість), а в сітці мініатюр відео
позначені значком відтворення.

## Можливості

**Переглядач**
* Вписування у вікно / масштаб 1:1 / вільне масштабування до 64×
* Плавне масштабування коліщатком до точки під курсором, панорамування перетягуванням
* Обертання, дзеркальне відображення по горизонталі та вертикалі
* Повний екран, слайдшоу
* Стрічка кадрів (клавіша `T`) — накладається поверх знімка й зникає разом
  із панеллю, тож ніколи не зменшує зображення; типово вимкнена
* Панель відомостей: розміри, обсяг, дата, камера, об'єктив, витримка,
  діафрагма, ISO, фокусна відстань
* Шаховий фон під прозорими PNG
* Напівпрозорий затемнений задник: крізь поле навколо фото видно розмите
  вміст вікон, що позаду (`Backdrop` / `CanvasDim` в ini)
* **Автопідгонка** (клавіша `A`, кнопка на панелі) — три режими:
  вимкнена (завжди 100%), масштаб картинки під вікно, або вікно під картинку —
  тоді вікно стає рівно розміром зображення плюс рядок заголовка, його вже не
  можна перетягнути в інше співвідношення сторін, а зображення заповнює кадр
  за будь-якого розміру вікна
* Кнопка **«…»** відкриває решту дій (обертання, дзеркалення, сітка, стрічка,
  провідник, шпалери, кошик), щоб не захаращувати панель

**Плеєр (для відео)**
* Таймлайн із перемоткою, пауза, крок ±5 / ±30 секунд
* Звук приглушується на час перемотки й відкриття — інакше медіарушій
  клацає на першому семплі після розриву
* **Кадр під курсором**: наведіть на таймлайн — над ним з'явиться мініатюра
  того місця у відео. Декодується окремим потоком із власним `IMFSourceReader`,
  тож перемотка ніколи не гальмує відтворення; запити злипаються — обробляється
  лише останній, і кадр довантажується вперед від ключового до точного моменту
* Анімація «−5 с / +5 с» на тому боці кадру, куди перемотуєте
* **Продовження з місця зупинки** для кожного відео окремо — позиція
  запам'ятовується між запусками (для файлів довших за 30 секунд)
* У повному екрані відео заповнює екран (фото, як і раніше, не розтягується
  понад 100%)
* Гучність із відсотком, вимкнення звуку, швидкість 0.5×–2×
* Кнопка «…» дає ті самі налаштування, що й для фото: масштаб, автопідгонка,
  обертання, дзеркалення, сітка, стрічка кадрів, відомості, кошик
* Панель відомостей для відео: роздільність, тривалість, кодеки, частота
  кадрів, бітрейти, канали й частота звуку
* Клік по кадру — пауза, подвійний клік — повний екран
* Гучність і режим звуку запам'ятовуються між запусками

**Сітка папки**
* Мініатюри всієї папки, регульований розмір
* Сортування за іменем / датою / розміром / типом
* Мініатюри беруться з кешу Провідника — тому теки, які ви вже відкривали,
  показуються миттєво

**Налаштування** (`Ctrl+,`, шестерня в заголовку або пункт у меню «…»)

Вікно з бічною навігацією, як у «Параметрах» Windows — п'ять розділів. У
вузькому вікні бічна панель автоматично стає рядком піктограм, а вміст
прокручується, тож налаштування відкриваються навіть у крихітному вікні.
Так само поводиться меню «…»: воно ніколи не вилазить за межі вікна, а що не
вміщається — прокручується коліщатком.

У рядку заголовка лишилися тільки закріплення та шестерня; перемикач теми й
довідка з гарячими клавішами живуть у налаштуваннях.

* **Вигляд** — **мова** (українська / English / русский), тема, задник вікна
  та його затемнення, стрічка кадрів
* **Перегляд** — автопідгонка, дія колеса, запам'ятовування масштабу,
  згладжування, гортання по колу, інтервал слайдшоу
* **Відео** — автовідтворення, продовження з місця зупинки, гучність
* **Вікна** — одне спільне вікно (швидко) або окреме вікно на кожен файл,
  закріплення поверх усіх вікон, кнопка «Нове вікно»
* **Формати файлів** — спершу найпоширеніші (jpg, png, heic, mp4, mkv…),
  нижче решта. Кнопка «Застосувати» реєструє позначені в меню «Відкрити за
  допомогою» (лише `HKCU`, без адмінправ), поряд — «Стандартні програми» Windows

Зміни зберігаються одразу, тож нові вікна одразу бачать новий режим.

**Загальне**
* **Три мови інтерфейсу**: українська, English, русский. При першому запуску
  мова береться з Windows, далі змінюється в налаштуваннях і застосовується
  миттєво
* Перетягування файлів у вікно
* Копіювання в буфер обміну (як зображення і як файл)
* Видалення в кошик (з можливістю відновити)
* Показати в провіднику, зробити шпалерами
* **Поверх усіх вікон** (`P`) — вікно не ховається за іншими
* Тема слідує за системною, перемикається вручну
* Підтримка HiDPI (per-monitor v2)
* Запам'ятовує масштаб, поворот і дзеркалення **для кожного файлу** окремо,
  а також останній відкритий файл, режим перегляду й повний екран
* Налаштування у `PictureGift.ini` поруч із exe — програма справді портативна

## Збірка

Потрібні **Build Tools for Visual Studio** з компонентом
«Desktop development with C++» (робоче навантаження C++ і Windows SDK).

```bat
build.bat
```

Скрипт сам знаходить `vcvars64.bat` через `vswhere`, збирає ресурси й лінкує
`PictureGift.exe` у корені проєкту. Статичний CRT (`/MT`), тому жодних
Visual C++ Redistributable не потрібно.

Структура:

```
src/pg.h        спільні оголошення
src/util.cpp    дрібні помічники, палітра теми, список файлів, налаштування
src/decode.cpp  конвеєр декодування (WIC + запасні декодери + EXIF)
src/loader.cpp  фоновий пул потоків із пріоритетами
src/gfx.cpp     D3D11 + DirectComposition + Direct2D
src/video.cpp   відтворення відео (Media Foundation Media Engine)
src/lang.cpp    таблиця перекладів інтерфейсу
src/ui.cpp      розмітка, малювання, взаємодія (immediate mode)
src/main.cpp    вікно, ввід, логіка застосунку
res/            іконка, маніфест, версія
```

Діагностика: якщо задати змінну середовища `PG_DEBUG=1`, програма пише
`picturegift.log` поруч із exe — там час кожного етапу старту й декодування.

## Налаштування (`PictureGift.ini`)

Файл створюється поруч з exe (або в `%LOCALAPPDATA%\PictureGift`, якщо тека
з exe лише для читання).

| Ключ | Значення |
|---|---|
| `ThemeMode` | 0 — як у системі, 1 — темна, 2 — світла |
| `SingleInstance` | 1 — перевикористовувати запущене вікно (швидко), 0 — окреме вікно на кожен файл |
| `WheelMode` | 0 — колесо масштабує, 1 — колесо гортає |
| `SlideshowMs` | інтервал слайдшоу, мс |
| `ThumbSize` | розмір мініатюр у сітці |
| `Smoothing` | 1 — згладжування при збільшенні, 0 — різкі пікселі |
| `LoopFolder` | 1 — гортання по колу |
| `Filmstrip` | 1 — показувати стрічку кадрів (накладається, не зменшує фото) |
| `AutoSize` | 0 — автопідгонка вимкнена, 1 — масштаб під вікно, 2 — вікно під картинку |
| `RememberZoom` | 1 — запам'ятовувати масштаб і поворот для кожного файлу |
| `Fullscreen` | 1 — запускатися в повноекранному режимі |
| `LastFile` | файл, відкритий останнім (відкривається при запуску без аргументів) |
| `Associations` | розширення, зареєстровані в «Відкрити за допомогою» |
| `AlwaysOnTop` | 1 — тримати вікно поверх усіх інших |
| `ResumeVideo` | 1 — продовжувати відео з місця зупинки |
| `Lang` | 0 — українська, 1 — English, 2 — русский |

Позиції відтворення зберігаються в секції `[Resume]` того ж файлу
(до 120 останніх відео).
| `Backdrop` | 0 — без підложки, 1 — Mica, 2 — Acrylic, 3 — розмиття того, що позаду вікна (типово) |
| `CanvasDim` | 0–100 — наскільки затемнено задник (менше = крізь нього видно більше) |
| `Volume` | 0–100 — гучність відео |
| `Muted` | 1 — звук вимкнено |
| `AutoPlay` | 1 — відео починає грати одразу після відкриття |

Щоб разово відкрити файл в окремому вікні попри `SingleInstance`, тримайте
`Shift` при відкритті або запустіть із ключем `--new`.

## Асоціації файлів

Найзручніше — прямо в програмі: `Ctrl+,` → розділ **«Формати файлів»**,
позначте потрібні розширення й натисніть «Застосувати».

Windows 11 не дозволяє програмам мовчки ставати програмою за замовчуванням,
тож і застосунок, і скрипт нижче лише **додають PictureGift у список «Відкрити
за допомогою»** (гілка `HKCU`, без прав адміністратора) — далі ви самі обираєте
його в Провіднику або в «Параметри → Програми → Стандартні програми».

Той самий результат зі скрипта, якщо зручніше:

```bat
register.bat          :: додати в "Відкрити за допомогою"
register.bat /remove  :: прибрати
```
